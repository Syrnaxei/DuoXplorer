# 005 编辑标签按钮：7 色勾选菜单 + tagNames 写入

**Blocked by**: 002

## 目标
选中对象后点标签按钮，在 7 色菜单中勾选/取消标签并立即写入文件、列表刷新（分组激活时重新归组）。

## 涉及层
- [ ] 数据层：`FileSystemService` 新增写标签方法——读各选中对象现有 tags，`setResourceValue(_:forKey: .tagNamesKey)` 写回；复用 `FinderTag.all`
- [ ] 逻辑层：共同标签计算 = 所有选中对象 tags 的交集，用于菜单 ✓ 态；toggle = 应用（并入去重）或移除
- [ ] UI层：
  - 工具栏标签按钮（SF Symbol `tag`），无选中时 disabled
  - 点击弹出 NSMenu：7 项，每项左侧色点（`FinderTag.color`），共同标签带 ✓
  - 点击后写标签 → 刷新列表；分组激活时按新标签重新归组（走 002 的刷新路径）
- [ ] 测试：共同标签交集与 toggle 逻辑断言（临时文件写入/读回校验）+ 手动验证清单

## 验收标准
- 选中 1 个文件：菜单勾选态 = 该文件已有标签；点击「红色」后 Finder 中该文件显示红标签
- 选中 2 个文件（一红一无）：红色带 ✓；点击后两者都变红，再点一次都移除
- 按标签分组时打标签，条目立即移入对应组
- 写入后 Spotlight 侧边栏标签页能搜到（kMDItemUserTags 生效，可能延迟）
