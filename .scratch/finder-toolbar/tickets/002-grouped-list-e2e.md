# 002 真分组端到端：分组方式按钮 + 分节渲染 + 列头组内排序

**Blocked by**: 001

## 目标
点分组方式按钮选任一维度，目录列表立即按该维度分节显示（标题行 + 项目数），点列头只改组内排序；选「无」回到现有平铺。

## 涉及层
- [ ] 数据层：`MainContentView` 新增会话级 `@State groupDimension`（默认 .none，不持久化）
- [ ] 逻辑层：分组激活时把 `files` 经 `GroupingService` 展开为行模型（分组标题行 + 文件行）；标题行携带组名与项目数
- [ ] UI层：
  - 工具栏右上新增分组方式按钮（SF Symbol 原生风格图标），点击弹出 NSMenu：10 项按 spec 图二顺序，当前维度 ✓
  - NSTableView 行模型扩展：标题行不可选中、不可右键、不可拖拽、键盘导航跳过
  - 列头点击（HeaderCell）：分组激活时只更新组内排序（维度/方向），分节结构不变；「无」分组时保持现有全局排序行为
  - 搜索结果与标签模式保持平铺（分组不生效，按钮可点但无效或置灰，取实现更简者）
  - 目录切换/刷新后保持当前分组维度并重新归组
- [ ] 测试：行模型映射断言（分组开/关两种状态下 row index ↔ URL/标题行的映射、选中集合过滤标题行）+ 手动验证清单（交付时给出 build_and_run.sh + 逐条预期现象）

## 验收标准
- 选「种类」可见多节列表，节标题含组名和项目数
- 分组激活时点「大小」列头：节不变，节内条目按大小重排
- 选「无」后列表与改动前完全一致
- 搜索框输入后结果平铺，无标题行
- 标题行无法被选中或右键，空格/回车不会作用于标题行
