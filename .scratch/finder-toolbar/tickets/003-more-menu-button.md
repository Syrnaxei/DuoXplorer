# 003 ••• 菜单按钮：双形态弹出 + 空白区分组方式子菜单

**Blocked by**: 002

## 目标
点工具栏 ••• 按钮在按钮下方弹出与右键完全一致的菜单；空白区菜单里多一个「分组方式」子菜单。

## 涉及层
- [ ] 数据层：无新增
- [ ] 逻辑层：按钮点击时按 `selectedURLs` 是否为空取 `menuItems(for: nil / 代表文件)`，与右键同源；无选中时代表文件为 nil
- [ ] UI层：
  - 工具栏 ••• 按钮（SF Symbol `ellipsis.circle` 或原生等价），点击在按钮下方弹出 NSMenu（复用 FileListView 现有 FileMenuItem → NSMenu 构建路径）
  - 空白区形态追加「分组方式」子菜单：10 项 + 当前维度 ✓，与工具栏分组菜单同源构建（一个函数两处复用）
- [ ] 测试：菜单条目数据断言（两种形态的条目序列、子菜单勾选态）+ 手动验证清单

## 验收标准
- 无选中点 •••：菜单 = 空白区右键菜单 + 「分组方式」子菜单
- 选中文件点 •••：菜单 = 该对象右键菜单，动作作用于全部选中
- 子菜单切换分组后列表立即重新归组，且工具栏分组菜单勾选态同步
